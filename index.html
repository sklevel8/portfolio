How these are built

The demos are deliberately static: HTML, CSS and vanilla JavaScript, no bundler, no runtime secrets. Where a project has a real backend, the UI mirrors its actual contracts — the same transition table, the same validation rules, the same report fields — so the demo explains the system rather than impersonating it.

Honest demos

Simulated data is labelled as simulated. Real report files drive the dashboards where they exist.

Accessible by default

Semantic landmarks, visible focus, keyboard paths and reduced-motion support throughout.

Boring infrastructure

Static hosting, immutable asset caching and security headers set in netlify.toml.

Engineering notes

  • Integer cents, never floats
    Escrow amounts are parsed and compared as integers.
  • Base62 instead of hashing
    Short codes are reversible encodings of a row id — no collisions to retry.
  • One message per change
    Watchers diff state before notifying, so subscribers are not spammed.
  • Luhn before lookup
    Invalid identity numbers never reach a database query.
